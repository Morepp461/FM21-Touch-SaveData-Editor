# Privacy Policy

**App:** FM21 Touch Save Editor  
**Effective date:** 10 November 2026

FM21 Touch Save Editor is an offline utility for inspecting Football Manager Touch 2021 save files.

## Information the app processes

The app processes a save file only after the user selects it through Android's system file picker. Depending on the feature used, it reads save metadata, component names and data needed to display comparisons or person-record indexes.

The app may create a component export or CSV file only when the user explicitly selects an export action and chooses a destination in Android's system save dialog.

## Storage and transmission

- Save files are processed locally on the device.
- The app does not upload save files to a developer server.
- The app does not include analytics, advertising SDKs, account registration or cloud sync.
- The app does not request broad storage access. It uses Android's Storage Access Framework for user-selected files.
- The app manifest does not request Internet permission.

## Retention and deletion

The app does not maintain a remote copy of selected files. Temporary processing files may be created in the app's private cache. Import staging files are deleted after parsing, and prepared export files are deleted after the export callback completes or is cancelled. If the app or device is interrupted before cleanup runs, a temporary file may remain until Android clears the cache or the user clears app storage through Android settings. Users can remove exported files from the destination they selected.

## Children's privacy

The app is a general-purpose file utility and does not knowingly collect personal information from children.

## Third-party services

The app does not send user data to third-party services as part of its current functionality.

## Changes to this policy

If future versions add analytics, advertising, accounts, cloud processing or other data transmission, this policy and the app's disclosures must be updated before those features are released.
